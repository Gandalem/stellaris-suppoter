# TASK-033 무기 자원 분류와 반복 안내 수정

2026-10-25 사용자 요청: mult 오표시와 안구 광선 안내 반복을 해결하고 추가 데이터 문제를 확인한다. 전체 수정 코드 작성 후 필수 검사와 저장 자료 전체 점검을 진행했다. [구조화 결과](TASK-033-weapon-resource-fix.json).

## 수정

mult/multiplier·trigger·inline_script 등 경제 제어 항목을 자원 목록에서 분리했다. cost/upkeep별 resource_scopes와 읽기 정책 weapon-resource-scope-2를 반환하고, 제어·불완전·중복 범위와 원문 위치를 보존한다. 배율/조건/인라인 구문이 있으면 선언 숫자를 최종 비용으로 사용하지 않으며 value와 number를 함께 비운다. 독립된 유지비 0과 정상 피해·거리 등 다른 수치는 유지한다.

추가로 중복 cost/upkeep 블록을 첫 값/마지막 값으로 선택하거나 합산하지 않고 개별 선언 후보로 보존했다. 조건·배율·중복 금액은 카드와 상세에서 각각 짧은 비용 상태로 보여준다. 일반 비용과 동적 비용을 같은 확정 숫자로 표시하지 않는다.

변이 표의 기존 policy_required와 원문 선언/출처는 유지한다. 상세·요약 카드·접근성 텍스트·갱신 미리보기에서 해당 안내를 한 번만 표시한다. 확정된 일반 무기 수치와 제작 비용은 그대로 보인다. 값 근거 패널을 복원하거나 변이 엔진 적용 결과를 임의 계산하지 않았다. 스냅샷 중립 제품은 재사용하므로 추가 색인이 필요 없다.

## 추가 데이터 점검

기존 개인 검사 스냅샷의 무기 정의 555개를 모두 읽었다. 현재 설치의 자원 정의 26개와 직접 추출된 자원 ID를 대조했다. 알 수 없는 자원 ID, 제어 항목의 자원 유출, 조회 실패, 변이 안내 중복은 발견되지 않았다. 전체 실행 관측값은 111.638초다.

| 추가 해석 범위 | 정의 수 | 처리 |
|---|---:|---|
| 변이 표 적용 규칙 | 247 | 선언과 근거를 보존하고 수치를 확정하지 않음 |
| 조건·배율·인라인·중복이 있는 비용 범위 | 300 | 동적/중복 상태로 표시하고 고정 비용으로 계산하지 않음 |
| 위 비용 범위 중 중복 선언 | 43 | 개별 후보를 유지하고 합산/마지막 값 선택을 하지 않음 |

247개와 300개 범위는 겹친다. 43개는 300개에 포함된다. 추가 해석이 필요한 정상 게임 구문 범위이며 새 자원 오분류나 조회 실패 건수로 세지 않는다. 다음 데이터 확장은 변이 표 적용 규칙과 인라인/조건 비용을 각 문맥에 맞게 해석하는 작업이다.

전체 필드 상태는 resolved 4,087개, missing 472개, policy_required 3,211개다. 선택적 필드의 정의 없음은 0으로 채우지 않았다. 이 외 unsupported/incomplete 등의 추가 수치 오류 상태는 이번 555개 범위에서 나타나지 않았다. 비용의 incomplete/ambiguous 상태는 별도의 자원 범위에 보존한다.

## 근거

설치된 무기 정의·비용 인라인 스크립트와 자원 정의를 읽기 전용으로 확인했다. 게임 원문은 공개 문서에 복제하지 않았다. 웹에서는 [Microsoft 문구 지침](https://learn.microsoft.com/en-us/windows/apps/design/style/writing-style)을 참고해 같은 원인의 안내를 간결하게 묶었다. 엔진의 변이/비용 계산 규칙을 외부 게시글에서 추정해 추가하지 않았다.

최종 전체 Ruff와 원장/링크 정합성 검사 통과. 정합성 검사는 제품 테스트 수에 포함하지 않았다.
