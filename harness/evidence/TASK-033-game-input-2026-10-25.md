# TASK-033 — 게임 입력 통과 확인

2026-10-25. 사용자가 카드 보기 상태의 게임 클릭·드래그·키 입력 확인을 요청했다. 제품 코드와 실행 파일은 변경하지 않았다.

## 실행한 확인

Windows Computer Use 초기화가 입력 전에 `helper_sandbox_lock_failed / SetNamedSecurityInfoW sandbox dir failed: 5`로 실패했다. 보안 설정을 변경하거나 별도 입력 주입 수단으로 우회하지 않았다.

실행 환경에서 경로/PID/HWND로 게임 대상 하나를 읽기 전용으로 감지했다. 클라이언트 2560×1440, DPI144, 관측 시 해당 창은 전경이 아니었다. 이 관측을 실제 게임 클릭/키 수신으로 해석하지 않는다.

화면 밖의 자체 검사 창에서 제품 CardWindow.present를 호출해 opacity 30/90/100 각각 passive→interactive→passive의 9개 상태를 검사했다. passive에서 layered/mouse-transparent/no-activate가 모두 켜졌고 interactive에서는 mouse-transparent/no-activate가 해제됐다. 100% 불투명도 passive에서도 layered가 유지됐다. 입력 이벤트는 게임이나 다른 사용자 창에 보내지 않았다. 이 검사는 OS 설정 확인이며 게임 수신 확인을 대신하지 않는다.

[Microsoft layered window 문서](https://learn.microsoft.com/en-us/windows/win32/winmsg/window-features)의 layered+transparent 입력 전달 설명과 현재 구현을 대조했다. [파일 접근 권한 문서](https://learn.microsoft.com/en-us/windows/win32/fileio/file-security-and-access-rights)는 화면 도구 초기화의 접근 권한 오류를 확인하는 참고로만 사용했으며 권한을 바꾸지 않았다.

## 실제 게임 수용

사용자에게 카드가 덮은 버튼 클릭, 카드 위 지도 드래그/영역 선택, Esc 등 게임 키 반응을 요청했다. 타이틀 상태라면 드래그는 미확인으로 남기도록 구분했다. 관측을 받기 전 실제 입력 통과를 통과로 올리지 않는다. 전체 E-046/E-048 상태는 유지한다.

제품 실행 파일 hash는 검사 전후 일치했다. 원본 게임/사용자 설정을 수정하지 않았으며 Git 작업이나 재빌드는 하지 않았다. 세부 결과: [JSON](TASK-033-game-input-2026-10-25.json).


## 사용자 클릭 통과 확인

사용자가 타이틀 화면에서 ‘카드뒤에 있는 게임 버튼 잘클릭되’라고 보고했다. 실제 카드가 덮은 게임 버튼의 클릭 수신은 pass로 기록한다. 카드 보기 상태에서 카드 자체가 움직이지 않는 동작은 입력 통과 모드의 의도된 동작이며, 카드 이동은 편집 모드에서 제목줄을 드래그하는 것으로 구분했다. 게임 지도 드래그는 타이틀 상태라 not_run, 키 입력은 추가 관측이 필요하다. 전체 OVL-05/E-046/E-048을 통과로 올리지 않는다.


## 사용자 키 입력 통과 확인

사용자가 ‘게임 설정 창을 열고 Esc로 잘되’라고 보고했다. 카드 보기 상태에서 게임 설정을 열고 Esc로 닫는 키 수신은 pass로 기록한다. 이전 카드 뒤 버튼 클릭 pass를 유지한다. 이후 제공된 이미지는 플레이 화면이지만 이미지 자체로 게임 지도 드래그 수신을 판단하지 않는다. 카드 위 드래그에 의한 게임 지도 이동/영역 선택은 명시적 관측이 없어 not_run이다. 전체 E-046/E-048 상태는 유지한다. 제품 코드는 변경하지 않았다.


## 사용자 드래그 통과 확인 및 이번 항목 완료

카드 위에서 게임 지도 이동/영역 선택 드래그가 되는지 요청한 뒤 사용자가 ‘어 잘되네’라고 확인했다. 실제 게임 드래그 수신도 pass로 기록한다. 요청한 카드 보기 상태의 클릭·드래그·키 입력 세 항목은 현재 사용자 환경의 관측을 근거로 완료했다. 화면 도구가 직접 조작한 결과로 표현하지 않는다. 다른 화면 모드/DPI/모니터나 전체 E-046/E-048 수용까지 확대하지 않는다. 다음 범위는 창 전환·최소화/복원·게임 종료 시 카드 숨김/복귀와 위치·크기 보존이다. 제품 코드/실행 파일 변경 없음.
