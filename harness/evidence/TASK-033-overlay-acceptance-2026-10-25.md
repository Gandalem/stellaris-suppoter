## 사용자 실제 화면의 추가 관측

사용자는 ‘숨기고 나오는 건 잘된다’고 보고했고, 게임 위 검색·카드 편집 창이 표시된 화면을 제공했다. 3회 토글·포커스와 입력 통과는 별도 관측이 없으므로 통과로 올리지 않는다.

관리창 검색 화면은 ‘청색 레이저’ 입력 후 결과 0개 및 `error` 상태였다. 오버레이 검색창도 결과 목록이 비어 있었다. 사용자가 실제로 실행 중인 앱에서 검색이 실패한 것은 확인된 문제다. 그 상태에서는 기술 카드를 고정할 수 없어 카드 표시·입력 통과 검사는 선행 검색 실패로 진행할 수 없다. 현재 UI는 상세 진단을 보여주지 않아 화면만으로 원인 코드를 판단할 수 없다.

추가로 동일 사용자 저장소를 사용한 별도 QThread Worker, offscreen Manager, 원본 실행 파일에서 읽은 archive 코드, 별도 console/windowed 동결 검사 프로그램의 Manager 경로에서 모두 결과 2개/partial/no worker error로 반환됐다. 별도 검사 프로그램은 ignored `.venv` 안에만 만들었으며 제품 소스·기존 테스트·원래 실행 파일은 변경하지 않았다. windowed 검사는 Windows Qt platform, 두 worker 종료까지 확인했다. 원래 실행 파일의 SQLite DLL은 개발 환경 DLL과 hash가 같았고 신규 핵심 저장 모듈도 archive에 포함돼 있었다. 따라서 현재 근거만으로 누락 모듈·SQLite 버전·데이터 손상 또는 특정 원인을 확정하지 않는다.

실행 중 앱의 완전 종료 후 재실행 검색 결과를 사용자에게 요청했다. 원본 제품/테스트/실행 파일 93개 hash는 추가 검사 후에도 일치한다. 코드는 수정하지 않았다. OVL-02 실제 화면 검색 실패를 우선 해결 대상으로 기록하며 이후 카드·입력 통과·재시작/DPI/모니터 수용은 보류한다.


## 완전 종료 후 재실행 결과

원래 배포 archive와 정상 동작한 검사 archive의 전체 모듈 이름 집합이 같고 제품 모듈 43개의 바이트코드/상수/이름/함수 플래그가 일치했다. 누락 모듈이나 오래된 제품 코드라는 설명은 현재 비교 근거로 뒷받침되지 않는다. 실제 실행 중 오류 코드·예외가 UI에 표시되지 않아 최종 원인은 아직 확정하지 못했다.
