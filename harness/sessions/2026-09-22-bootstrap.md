## 설계에서 확정한 경계

첫 수직 슬라이스는 합성 기술 → 현지화 → SQLite → 검색 → 정확한 원문 출처 출력이다. v0.1은 오프라인·읽기 전용·모델 없는 정적 도우미이다. 모드 적용·세이브·계산·AI·외부 최신성은 후속 단계로 분리했다.

이전 대화의 특정 게임 패치·코드명·출시일은 검증값으로 채택하지 않았다. 실제 설치 경로·버전·OS·DLC·모드 상태는 미확인이다. Wiki 일부 본문을 확보하지 못한 점도 출처 목록에 기록했다.

기본 CLI TASK-013과 refs TASK-015, diff TASK-016을 구별한다. 평가 runner TASK-018은 자동 평가 실행 체계를 만들되 아직 구현되지 않은 성능·패키징·실제 게임·후속 기능을 pass로 만들지 않는다. E-035/036은 TASK-019/020에서 실행 근거를 채우고 E-037/038은 실제 검증·릴리스 때 처리한다.

## 검증

Linux, Python 3.13.5의 로컬 작업 공간에서 다음을 실제 실행했다.

```sh
python -m unittest discover -s tests_harness -v
```

결과: exit 0, 18 tests, OK. 이는 작은 합성 문서 저장소를 사용하는 검사기 회귀이며 제품/게임 테스트가 아니다. 전체 원격 문서 묶음의 검사와 GitHub CI 상태는 [검증 기록](../evidence/bootstrap-checks.md)에 별도로 기록한다. 로컬 작업 공간은 전체 저장소 clone이 아니므로 이 실행으로 전체 원격 문서 링크를 검증했다고 주장하지 않는다.
