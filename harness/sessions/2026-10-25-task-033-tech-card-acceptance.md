# TASK-033 — 기술 카드 실제 표시 확인

날짜·시간대: 2026-10-25 / Asia/Seoul
사용자 요청: 새 기술 카드의 실제 사용 화면 제공.
작업: TASK-033, 기존 개발 범위의 사용자 앱 표시 확인.

## 실제 수행

처음 이미지의 변수 자료 없음 상태를 코드의 legacy 분기와 대조했다. 검색 자료 선택 경로와 Qt 공식 ComboBox 문서를 읽었으나 제품 코드를 수정하지 않았다. 에이전트에서 읽은 기본 저장소는 기존 자료/카드 없음 상태여서 실제 사용자 앱 상태로 간주하지 않았다.

이어 사용자가 제공한 검색·상세·오버레이 화면 모두에서 기본 비용 1,250, 물리학·1단계, 선행 적색 레이저와 읽을 수 있는 한글을 확인했다. 상세 설명과 원래 표현 @tier1cost2도 표시됐다. [근거](../evidence/TASK-033-tech-card-info-option-2.md), [구조화 결과](../evidence/TASK-033-tech-card-info-option-2.json).

## 검증 범위

사용자 이미지로 실제 앱의 새 기술 정보 표시를 확인했다. 자동 검사를 반복하지 않았다. 출처 파일 열기, 기존 UID/크기 보존, 전체 DPI/다중 모니터/종료 잔여 창까지 통과로 확장하지 않는다. 사용자 설정·DB·제품·실행 파일 변경 없음. 커밋·푸시·PR·병합·배포 없음.

## 인계

새 기술 카드 정보 표시 확인은 완료됐다. 다음 남은 수용 항목은 화면 배율/모니터 경계에서의 위치·크기와 프로그램 종료 시 카드 창 정리다. 이미 확인한 비용/기술명/기본 입력 통과/재실행/창 전환 검사를 반복하지 않는다. TASK-033 doing 및 전체 E-046/E-048 상태 유지.


## 종료·재실행 후속

사용자가 프로그램 종료 시 카드 전부 사라짐과 재실행 시 다시 표시됨을 확인했다. [창 수명주기 근거](../evidence/TASK-033-window-lifecycle-2026-10-25.md)에 해당 항목을 pass로 반영했다. 다음 남은 수용 범위는 정확한 배율/모니터/좌표이며, 확인된 동작을 반복 검사하지 않는다. TASK-033 및 전체 E-046/E-048은 기존 상태를 유지한다.


## 배율·모니터 후속 및 다음 기능 제안

사용자가 배율·모니터의 카드 위치/크기 유지도 정상이라고 응답했다. 현재 사용자 환경의 관찰로 기록하며 전체 환경 행렬을 승인하지 않는다. 다음 코딩 작업을 질문해 기존 부품 adapter와 설치 파일의 명시적 기술 요구 관계를 읽고, 함선 부품 조회와 기술 상세의 관련 부품 연결을 제안한다. 추가 기능은 아직 승인·구현하지 않았다. 커밋/푸시/통합은 별도 사용자 시점을 유지한다.
