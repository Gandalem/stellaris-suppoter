# 2026-10-25 — 무기 상세 값 근거 UI 제거

사용자 요청에 따라 무기 상세의 값 근거 전용 영역을 제거하고 수치/자원/조건/특수 작용/원문 및 기술 연결을 보존했다. 기술 상세 탭은 기존 상태를 유지한다. 기능 작성 완료 후 기존 화면 이동 검사 1개와 실제 자료 화면 렌더링을 통과했다.
