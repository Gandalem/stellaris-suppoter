# TASK-033 — 코드 변경 전 후속 검사

사용자가 다음 작업의 모든 검사를 요청했다. 제품/테스트/패키지 코드는 변경하지 않았다. [검사 근거](../evidence/TASK-033-overlay-acceptance-2026-10-25.md)에 실행 범위와 남은 실제 게임 수용을 구분했다.

기존 desktop 16개 통과, 실제 사용자 데이터 Worker/CLI 검색·고정 카드·출처 24개/필드 11개·선행 관계 1개 대조, 격리 설정 왕복, self-diff 카드, 자체 창 API, 실제 데이터 실행 파일 smoke 통과. 시작/종료 코드·실행 파일 93개 hash 일치.

게임 창 감지 1개/2560×1440/DPI144. 화면 조작 도구 2종은 Windows 권한 오류로 시작하지 못했다. 사용자에게 실제 게임 3회 토글·입력 통과·숨김·창 전환/최소화 관측을 요청했다. 실제 화면/입력 관측을 받기 전 E-046/E-048 not_run, TASK-033 doing을 유지한다. 코드 수정, Git 통합, 재빌드는 실행하지 않는다.

추가 사용자 관측: 창 표시·숨김은 동작하지만 관리창 검색은 결과 0/error, 오버레이 검색 목록도 비어 있음. 격리 QThread/Manager 및 별도 console/windowed 동결 검사에서는 동일 데이터 2개 결과가 반환됐다. 원인은 확정하지 않았으며 원래 앱의 완전 종료/재실행 결과를 요청했다. 검색 실패 때문에 실제 카드·입력 수용은 보류했다. 제품/기존 테스트/원래 실행 파일 93개 hash 불변.

사용자가 완전 종료/재실행 후에도 동일 검색 오류라고 확인했다. 원래 배포와 진단 archive의 모듈 집합 및 제품 43개 모듈 코드가 일치한다. 검색 실패 및 오류 상세 미표시를 수정 대상으로 남겼으며 코드는 변경하지 않았다.
