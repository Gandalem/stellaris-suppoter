# 관리창 첫 색인·검색 오류 진단

관리창은 자기 실행 환경에서 읽는 사용자 저장소를 기준으로 동작한다. 다른 실행 환경에서 같은 경로 문자열에 색인을 저장했다는 사실만으로 사용자 앱의 데이터 준비를 완료로 판단하지 않는다. 파일 식별·크기·스냅샷 수·활성 포인터와 실제 사용자 앱의 검색 결과를 구별한다.

검색할 데이터가 없는 첫 실행에서는 관리창과 오버레이의 검색 입력을 비활성화하고 홈의 색인 작업을 안내한다. 사용자가 색인을 시작하면 단계와 처리 파일 수를 홈에도 표시한다. 작업 중 이벤트/부분 구문/전체 처리 선택은 고정한다. 완료 후 조회 가능한 스냅샷 목록을 갱신하고 검색 입력을 활성화한다.

PARTIAL_INDEX는 데이터를 읽었지만 활성화 동의가 없는 상태다. GUI는 부분 정보와 원문을 보존한 채 사용할지 한 번 묻고, 사용자가 동의했을 때만 partial 허용 재시도를 한다. 이미 완료한 파일 결과는 재사용한다. 사용하지 않으면 기존 활성 데이터는 보존한다. 다른 오류·취소를 이 동의로 우회하지 않는다.

검색 실패 시 관리창과 오버레이에 사람이 읽을 수 있는 안내와 오류 코드를 표시한다. 오버레이의 안내 행은 선택/카드 고정을 허용하지 않는다. 빈 결과와 실패는 구별한다.

개인 data_dir의 diagnostics/errors.jsonl에 실패 단계·예외 타입·SQLite 오류·경로를 뺀 코드 프레임과 저장소 메타데이터를 기록한다. 검색어·게임 원문·임의 예외 값·절대 경로는 기록하지 않는다. SQLite/SnapshotError의 제어된 설명은 포함한다. 파일 크기는 256KiB에서 회전하고 이전 파일 1개를 유지한다. 로그 기록 실패가 본래 오류를 바꾸지 않는다. 외부 전송은 없다.

개발자용 실행 파일 확인:

```text
StellarisSupporter.exe --diagnose-search "청색 레이저" --diagnostics-output <개인 결과.json>
```

정상 GUI worker 경로로 한 번 검색하고 종료한다. 선택한 스냅샷이 없으면 같은 worker가 SNAPSHOT_NOT_READY를 반환한다. 출력에는 질의 원문을 넣지 않고 상태·결과 수·진단 코드·저장소 식별 메타데이터를 기록한다. 실제 게임 클릭/키 입력 통과나 다중 모니터 수용을 대신하지 않는다.

근거: [검색/초기 색인 수정 기록](../harness/evidence/TASK-033-search-startup-fix.md).
공식 진단 참고: [PyInstaller](https://pyinstaller.org/en/stable/when-things-go-wrong.html), [Windows 파일 식별](https://learn.microsoft.com/en-us/windows/win32/api/winbase/ns-winbase-file_id_info).


## 카드 중복과 별도 창 테마

같은 종류·스냅샷·정의·관계 깊이의 카드는 다시 고정할 때 기존 항목을 선택한다. ID가 같아도 정의나 스냅샷이 다르면 별도 카드다. 기존 위치·크기·표시 항목을 덮어쓰지 않는다. 카드 수 한도는 신규 생성에만 적용한다.

이미 저장된 중복은 고정 카드의 ‘중복 정리’로 처리한다. 내용과 표시 항목이 같은 항목만 후보로 잡고, 사용자가 동의하면 먼저 개인 설정을 before-card-cleanup 이름의 별도 JSON에 백업한다. 첫 항목의 위치/설정을 유지하고 나머지를 제거한다. 백업 또는 저장 실패 시 기존 목록을 유지한다. 스냅샷·정의·깊이·표시 항목이 다른 카드는 합치지 않는다.

카드는 부모 없는 독립 Qt 창이므로 관리창의 stylesheet에 의존하지 않고 같은 theme을 직접 적용한다. 기술 카드 제목은 검증된 표시 이름을 사용한다. Qt 근거: [stylesheet 적용 범위](https://doc.qt.io/qt-6.12/stylesheet.html).

미리보기는 캡처 전 글꼴과 한글 glyph를 확인한다. offscreen 환경에서 글꼴이 0개라면 설치된 Segoe UI/맑은 고딕을 검사 프로세스에 직접 등록한 뒤 다시 렌더링한다. 네모 글자가 보이는 이미지는 시각 검수 통과로 처리하지 않는다. 글꼴 파일을 제품에 임의 복제·포함하지 않는다.
