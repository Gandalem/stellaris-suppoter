# 릴리스·완료 정의

문서 부트스트랩은 게임 도우미 릴리스가 아닙니다. 실행 파일·패키지·모델·게임 데이터가 제공된 것처럼 표시하지 않습니다. 현재 제품 버전은 미출시입니다.

## preview 게이트

TASK-001~020이 완료되고 관련 합성 평가가 통과해야 합니다. clean install, CLI 계약, source span, 한국어 검색, unknown/partial, snapshot 격리, 변경/복구, 개인정보·오프라인 테스트를 포함합니다. 지원 범주·미지원 구문·검증하지 않은 OS를 README에 명시합니다. 실제 게임 검증이 없으면 preview라고 표시합니다.

## 검증된 v0.1 게이트

TASK-021의 로컬 read-only 검증 기록이 필요합니다. 검증한 OS, 게임 버전 증거, branch, snapshot, 모드 미적용/적용 구분, 도메인 coverage, 실패/부분 성공과 제한을 기록합니다. 설치 데이터 일부를 확인했다고 모든 게임 규칙·DLC·모드를 검증했다고 표현하지 않습니다.

TASK-022는 아래 점검표와 근거를 제출합니다. 하나라도 미실행이면 이유와 남은 작업을 남깁니다.

- 기능/작업/평가 원장의 상태와 실제 구현·실행 근거가 일치한다.
- 설치·실행·업데이트·복구 안내가 깨끗한 환경에서 재현되었다.
- 패키지에는 실제 게임/DLC/모드 원문, 세이브, DB, 개인 경로, 비밀 값이 없다.
- 의존성 버전·사용 조건·앱 라이선스의 소유자 결정과 검토 상태가 기록되었다.
- 변경 기록, 호환성 범위, 알려진 문제, rollback 방법이 있다.

## 버전 정책

앱 버전, DB schema_version, parser/adapter 버전, 게임 버전, 공식 자료 확인일을 별도로 유지합니다. API/CLI/JSON 호환성 변경은 breaking 여부와 migration을 기록합니다. 과거 평가 결과는 해당 commit과 환경에 한정됩니다.

릴리스 태그·GitHub Release·패키지 게시·배포는 소유자 승인 후 수행합니다. 체크리스트 문서를 작성한 것만으로 게시 승인이 된 것은 아닙니다. 소유자가 앱 라이선스를 선택하기 전 임의 LICENSE를 넣지 않습니다.
