# 기술 카드 정보 개선 — 1안 초안

목표는 게임 중 이름·기본 비용·선행 기술을 빠르게 읽을 수 있는 카드다. 기존 검색·출처·스냅샷·카드 저장과 입력 통과를 활용한다. 이번 문서는 설계 초안이며 개발 착수나 기존 계약 변경을 승인하는 문서는 아니다.

## 1. 현재 화면에서 바꿀 부분

| 현재 표시 | 제안 표시 |
|---|---|
| 제목과 본문에 기술 이름 반복 | 제목에 한 번 표시 |
| physics / tier = 1 | 물리학 · 1단계 |
| 연구 비용 = @tier1cost2 | 기본 연구 비용 1,250 |
| 선행 기술 = { "tech_lasers_1" } | 선행 기술: 적색 레이저 |
| literal / unsupported_expression 반복 | 필요한 항목에만 값 확인 상태를 짧게 표시 |
| 스냅샷·파일 경로·해시가 본문 차지 | 상세·출처 보기에서 표시 |

위 비용 예시는 현재 설치의 해당 기술과 공통 변수 정의를 읽어 확인한 기본값이다. 제국·난이도·연구 관련 보정이 반영된 현재 게임의 최종 비용을 뜻하지 않는다.

## 2. 기본 카드 구성

표시 우선순위는 이름 → 분야/단계 → 기본 연구 비용 → 선행 기술 → 선택적 설명이다.

```text
청색 레이저
물리학 · 1단계

기본 연구 비용   1,250
선행 기술        적색 레이저

[설명 최대 2줄]
```

- 기술명은 현재 카드에 고정된 스냅샷의 한국어 이름을 사용한다. 번역이 없으면 영어, 둘 다 없으면 ID를 사용한다.
- 분야·단계·분류는 한국어 라벨로 표시한다. 이름을 확인할 수 없는 분류는 원문을 보존하고 상세 보기에서 설명한다.
- 선행 기술은 기존 관계 데이터와 같은 스냅샷의 번역을 연결해 목록으로 보여준다. 정적 선행 ID 목록을 실행 불가능한 수식으로 표시하지 않는다.
- 기본 카드는 선행 기술을 최대 3개까지 표시하고 나머지는 ‘외 N개’로 접는다. 전체 목록은 상세 보기에서 유지한다.
- 설명은 선택 항목이며 최대 2줄로 제한한다. 게임 번역에서 읽은 설명만 사용하고, 문장을 새로 만들어 효과를 보충하지 않는다. 동적 표현을 완전히 처리하지 못한 설명은 원문·상태와 함께 상세 보기에서 제공한다.
- 값이 0인 경우와 항목이 없는 경우를 구별한다. 확인할 수 없는 값은 ‘값 확인 필요’, 선행 기술이 없는 것이 확인되면 ‘없음’으로 표시한다.
- 카드 전체 상태 문구는 한 번만 표시한다. 나머지 정상 항목에 같은 경고나 기술 코드를 반복하지 않는다. 전체 데이터의 분석 범위와 개별 항목의 해석 상태는 내부 데이터에서 구별해 보존한다.

새 카드의 초기 크기는 96-DPI 기준 360×260을 기준으로 잡고, 실제 내용에 맞게 줄바꿈한다. 작은 카드에서는 설명 등 선택 항목부터 줄이고 비용과 선행 기술을 우선한다. 기존 카드의 위치·크기·투명도·표시 항목 선택은 유지한다. 전체 앱 디자인 개편은 포함하지 않는다.

## 3. 기본값 해석 범위

숫자 자체와 근거가 확실한 정적 변수 참조만 처리한다.

| 입력 | 처리 |
|---|---|
| 직접 적힌 유한한 숫자 | 원래 수치를 유지하고 읽기 쉽게 자리 구분 |
| 같은 파일에서 범위가 확인된 정적 숫자 변수 | 참조 위치와 변수 정의를 함께 근거로 표시 |
| common/scripted_variables의 단일 정적 숫자 정의 | 같은 스냅샷의 정의를 찾아 기본값 표시 |
| 누락·중복·범위가 불명확한 변수 | 임의 선택 없이 값 확인 필요 |
| 산술식·조건문·게임 실행 상태가 필요한 값 | 기본값을 만들어내지 않고 상세 원문 제공 |

1안은 변수 간 연쇄 계산과 일반 수식 계산을 포함하지 않는다. 로컬/공통 변수의 범위와 선택 근거를 분명히 확인한 경우만 사용하며, 같은 이름이 보인다는 이유로 임의 우선순위를 적용하지 않는다. 숫자는 부동소수점 오차나 임의 반올림 없이 원래 값을 보존한다.

비용의 근거는 기술의 cost 필드, @변수 참조, 변수 정의의 출처를 따로 유지한다. ‘1,250’이라는 표시값에서 그 근거까지 따라갈 수 있어야 한다.

## 4. 상세·출처 보기

검색·편집 모드에서 상세 보기를 누르면 관리창의 기술 상세 화면으로 연결한다. 기본 카드 크기를 갑자기 늘려 게임 영역을 덮지 않는다.

상세 화면에는 다음을 묶어 제공한다.

- 전체 설명과 선행 기술 목록
- 표시한 값, 원래 표현식, 해석에 사용한 변수 정의
- 기술 ID, 데이터 기준, 번역 대체 여부, 부분 분석 사유
- 파일·줄 위치와 원문 보기
- 해시·스냅샷·진단 코드는 접힌 기술 정보 영역

카드 보기 모드에서는 버튼과 제목 드래그를 받지 않고 기존대로 게임 입력을 통과시킨다. 상세 보기·선행 기술 열기·표시 항목 변경은 검색·편집 모드에서만 조작한다. 긴 설명을 hover나 툴팁에만 넣지 않는다.

선행 기술은 관리창의 기존 참조 조회로 연결한다. 같은 ID에 정의가 여러 개 있으면 후보를 구별하고, 다른 정의나 스냅샷의 정보를 합치지 않는다. 기술 트리 그림과 연구 경로 추천은 별도 후속 범위다.

## 5. 데이터와 기존 카드 연결

변수 파일은 기술과 함께 수집해 새 스냅샷의 원문·해시·출처에 포함한다. 변수 정의가 바뀌면 관련 기본값도 다시 계산하고, 누락·중복 상태 변화도 반영한다. 확인한 파일 결과와 기존 증분 저장 구조를 재사용한다.

카드용 표시 데이터는 원문 정보와 분리한다. 기존 AnswerFact의 raw_expression과 SourceRef를 덮어쓰지 않고, 표시할 기본값·해석 상태·관련 출처를 별도로 연결한다. 검색·CLI·원문 패널의 기존 정보는 유지한다.

처음 적용할 때는 변수 파일을 포함해 한 번 색인한다. 새 카드는 새 스냅샷을 사용하고, 기존 카드는 사용자가 ‘현재 데이터와 비교’ 후 갱신하도록 한다. 과거 스냅샷에 변수 출처가 없으면 최신 설치 파일의 값을 섞지 않는다. 이전 카드의 원문과 데이터 기준은 그대로 남긴다.

표시 항목 키, 카드 UID, 중복 판단 기준과 설정 저장 구조는 유지하는 방향을 우선한다. 새 기술·외부 서비스·AI 호출·게임 메모리 접근은 필요하지 않다.

## 6. 이번 범위와 다음 범위

**이번 범위:** 카드 전용 정보 구성, 한국어 라벨, 비용의 정적 기본값, 선행 기술 이름, 선택적 설명, 상세·출처 연결, 기존 카드 호환.

**후속 범위:** 현재 세이브를 반영한 실제 연구 비용·완료 시간, 기술 등장 확률, 제국/DLC/모드에 따른 사용 가능 판정, 부품 성능 추론, 기술 트리 그림, 연구 경로 추천.

## 7. 개발 순서와 완료 기준

1. 카드 표시 항목과 기본/상세 화면 구성을 고정한다.
2. 변수 파일 수집과 출처를 갖는 정적 기본값 처리를 연결한다.
3. 카드 전용 표시 데이터를 만들고 기존 원문 정보와 함께 전달한다.
4. 기본 카드와 상세 화면을 연결하고 기존 카드 설정·입력 통과를 유지한다.
5. 구현 100% 이후 필수 검수만 진행한다.

필수 확인은 청색 레이저의 기본 비용과 선행 기술 이름, 누락/중복 변수 처리, 변수 변경 전후 스냅샷 분리, 기존 카드 유지, 한글·긴 이름·작은 카드 표시, 카드 보기/편집 모드의 입력 동작이다. 확인이 끝난 뒤 실제 작성 내용과 남은 항목을 구분해 보고한다.

커밋·푸시·PR·병합·배포는 별도 실행 범위다.

## 참고

- 현재 제품의 presentation.py, AnswerFact/SourceRef, 증분 스냅샷 및 참조 조회 계약을 바탕으로 작성했다.
- 실제 설치의 기술 정의와 common/scripted_variables에서 예시 기본값의 연결을 읽기 전용으로 확인했다. 게임 원문 전체를 이 문서에 복제하지 않았다.
- [Microsoft Expander](https://learn.microsoft.com/en-us/windows/apps/develop/ui/controls/expander): 제한된 공간에서 세부 정보를 필요할 때 펼치는 구성 참고.
- [Microsoft Tooltips](https://learn.microsoft.com/en-us/windows/apps/develop/ui/controls/tooltips): 중요한 정보는 기본 라벨/본문으로 전달하는 원칙 참고.
- [Qt QLabel](https://doc.qt.io/qt-6/qlabel.html), [Qt Layout](https://doc.qt.io/qt-6/layout.html): 일반 텍스트·줄바꿈·레이아웃 적용 참고.
