# 불확실성·확인 대기 원장

아래는 아직 확인하지 않은 정보입니다. 설계 가정과 사실을 구별하고, 확인할 때 날짜·출처·환경·결과를 추가합니다. 현재 문서 날짜는 게임 최신성 검증일이 아닙니다.

| ID | 미확인 항목 | 임시 처리 | 해제 방법·시점 |
|---|---|---|---|
| U-01 | 사용자의 OS·설치 경로·설치 방식 | 경로 자동 가정 없음 | TASK-021 전 사용자 로컬 확인 |

이전 대화의 특정 패치 코드명·출시 일정·수치·폴더 목록은 이 원장의 확인 절차를 거치지 않았습니다. 반복 언급되었다고 사실로 승격하지 않습니다.

우선순위는 구현을 막는 것과 검증을 막는 것을 나누는 것입니다. U-01~09의 미확인은 합성 parser/검색기 개발을 막지 않지만 실제 게임 호환성 주장과 후속 계산의 근거는 제한합니다. unknown을 제거하기 위해 자료를 지어내지 않습니다.
