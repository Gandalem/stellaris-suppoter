# 제품 정의

## 목적

Stellaris Supporter는 사용자가 실제로 설치한 게임 데이터와 확인된 외부 자료를 버전별로 구분해 검색·설명하고, 이후 세이브와 계산 도구를 결합하는 한국어 중심 로컬 도우미입니다. '모든 것을 최신으로 학습했다'는 주장을 목표로 삼지 않습니다. 대신 **어떤 데이터·버전·시점·조건에 근거하는지 확인할 수 있는 답변**을 목표로 합니다.

저장소는 `Gandalem/stellaris-suppoter`, 배포명과 CLI는 `stellaris-supporter`, Python 패키지는 `stellaris_supporter`입니다. 게임 실행 파일이나 게임 콘텐츠를 재배포하는 프로젝트가 아닙니다.

## 사용 흐름

사용자는 설치 폴더를 직접 지정합니다. 도우미는 읽기 전용으로 안전한 목록과 해시를 만들고, 정적 스크립트와 번역을 연결해 개인 로컬 DB에 색인합니다. 사용자가 한국어 이름·영문 이름·내부 ID를 입력하면 같은 스냅샷 안에서 찾아 원문 위치와 한계를 함께 표시합니다. 게임이 업데이트되면 차이를 탐지하고 새 스냅샷을 생성합니다. 기존 스냅샷은 검증 전 교체하지 않습니다.

## v0.1 포함

| 영역 | 제공할 가치 | 보장하지 않는 것 |
|---|---|---|
| 환경·버전 | 설치 경로 검증, 데이터 지문, 버전 출처·미확인 표시 | 자동으로 최신 패치라고 단정 |
| 정적 데이터 | 기술부터 시작해 부품·건물·지구·직업·특성·정부 관련 항목·전통·승천·이벤트 정의 조회 | 엔진 실행, 실제 사용 가능 여부 전체 판정 |
| 현지화 | 한국어 → 영어 → ID 대체, 순환·누락 경고 | 모든 동적 텍스트의 게임 내 렌더링 |
| 검색 | ID·이름·별칭·짧은 한국어 검색과 범주 필터 | 임의 자연어 질문을 모두 이해 |
| 답변 | 필드 요약, 조건 원문, 파일·행·해시·스냅샷 근거 | 출처 없는 전략·수치·확률 |
| 관계 | 정적으로 확인된 선행 기술·참조 탐색 | 최단 승천 루트나 확률 시뮬레이션 |
| 운영 | 변경 감지, 재색인, 진단, 오프라인 사용 | 백그라운드 상시 갱신 서비스 |

DLC 파일의 존재, 소유권, 활성 상태는 별도입니다. v0.1은 설치 데이터의 정적 정의를 보여주며 '현재 세이브에 적용되는 규칙'이라고 표시하지 않습니다. 모드가 있어도 바닐라 조회는 가능하지만 모드 적용 결과 지원은 후속 단계입니다.

## 최초 데모

직접 만든 합성 데이터 `demo_tech_alpha`를 색인합니다. '합성 연구 알파', 영문 이름, ID로 같은 엔티티를 찾고 선행 기술과 비용 표현식의 원문을 표시합니다. 답변에는 `synthetic`, 상대 파일 경로, 행 범위, 스냅샷 식별자가 포함됩니다. 게임·인터넷·모델·API 키 없이 이 흐름이 테스트되어야 합니다. 이 데모를 실제 게임 호환성 증거로 사용하지 않습니다.

## 사용자 요구를 달성하는 후속 단계

v0.2: 공식 공지 수집·최신성 표시, 선택적 LLM 연결과 검색 기반 답변. v0.3: 검증된 모드 로드 순서와 세이브 읽기. v0.4: 입력·가정·오차가 명시된 경제·전투 계산과 UI. 각 단계는 [로드맵](ROADMAP.md)의 게이트를 통과해야 합니다.

## 성공과 제외

v0.1 성공은 합성 회귀 전부 통과, 출처 누락·스냅샷 혼합·원본 쓰기·무단 네트워크 0건, 사용자 로컬 수동 검증 결과 기록입니다. 로컬 검증 전에는 `preview`까지만 가능합니다. GPU·클라우드 비용·Codex는 v0.1 필수 조건이 아닙니다.

첫 버전에서 제외: 모델 파인튜닝, 벡터 DB·분산 서비스, 대규모 웹 크롤링, 게임 플레이 자동화, 온라인 계정 로그인, Steam 구매 내역 수집, 이미지/오디오 분석, 세이브 수정, 모든 패치·모드에 대한 완전 호환 보장.
