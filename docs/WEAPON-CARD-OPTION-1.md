# 무기 카드 고정과 기술 카드 연결 1안 초안

함선 설계 중 필요한 무기의 기본 수치를 게임 위에 남겨두고, 그 무기의 요구 기술과 상위 부품으로 이동해 필요한 카드를 추가한다. 기존 기술 카드의 보기·편집·숨김·저장 방식을 무기 카드에 확장한다.

## 1 사용 흐름

1. 관리창 무기 검색에서 계열을 펼쳐 소형·중형·대형 등 개별 부품을 선택한다.
2. 무기 상세에서 무기 카드 고정을 누른다.
3. 게임으로 돌아가 피해·사거리·명중·추적·전력·제작 비용을 참고한다.
4. Ctrl+Shift+Space로 편집 모드에 들어가 카드 위치·크기·표시 항목을 조정하거나 상세 보기를 연다.
5. 같은 자료의 상세에서 요구 기술 또는 명시된 상위 무기로 이동하고, 원하는 기술 카드나 무기 카드를 각각 고정한다.
6. 카드 보기로 돌아가 게임을 계속한다. Ctrl+Shift+H로 모두 숨길 수 있다.

한 번 고정하면 선택한 개별 무기와 자료를 유지한다. 카드가 연구 진행이나 다른 크기의 부품을 자동으로 따라 바꾸지 않는다.

## 2 카드의 기본 구성

| 위치 | 기본 표시 |
|---|---|
| 제목 | 무기 이름과 슬롯 크기 |
| 피해 | 기본 피해의 최소–최대 범위 |
| 사거리 | 최대 사거리, 직접 정의된 최소 사거리 |
| 명중과 추적 | 기본 명중률과 추적률을 백분율로 표시 |
| 전력 | 소비 전력 또는 공급 전력 |
| 제작 비용 | TXT 자원 선언의 자원별 비용 |

소형 청색 레이저라면 이름과 크기 아래에 기본 피해 8–21, 최대 사거리 40, 명중 90%, 추적 50%, 소비 전력 7, 합금 비용 15를 표시하는 구성을 사용한다. 실제 표시의 소수 자릿수는 현재 자료의 숫자 표현 규칙을 따른다.

사거리 하한이 없으면 최대 사거리만 표시한다. 수치 0과 자료 없음은 구분하고, 중복·미지원 식은 해당 항목에 짧게 표시한다. 전력 0은 전력 변화 없음으로 표시한다. 제작 비용의 여러 자원은 각각 표시하고 서로 다른 자원을 하나의 숫자로 합산하지 않는다. 카드에 넣을 수 없는 추가 자원은 외 N개로 알리고 상세에서 읽는다.

자료 기준은 카드 하단 한 곳에 둔다. 기본 게임 파일 기준과 필요한 경우 일부 자료·이전 자료를 표시하며, 실제 적용 패치나 현재 제국의 보정을 추정하지 않는다. 항목별 값 근거 패널은 추가하지 않는다.

## 3 표시 항목과 작은 카드

기본 항목은 피해·사거리·명중·추적·전력·제작 비용이다. 카드 관리의 표시 항목에서 아래 추가 항목을 선택할 수 있다.

- 선체·장갑·보호막 피해 배율.
- 장갑·보호막 관통률.
- 자원별 유지비.
- 요구 기술 이름.
- 추가 조건·특수 작용의 유무.

제목과 슬롯 크기는 항상 보인다. 기본 그룹은 위 순서를 사용하고, 기존 기술 카드의 항목 선택 방식처럼 선택한 항목을 저장한다. 모든 수치 항목을 끈 카드도 이름·크기로 식별할 수 있다.

무기 카드의 초기 크기는 96 DPI 기준 360×300으로 잡고 현재 화면 영역 안으로 제한한다. 기존 카드의 저장 크기는 바꾸지 않는다. 본문 내부 스크롤 없이 남은 높이에 맞춰 표시하고, 긴 이름·다수 자원·다수 요구 기술은 줄바꿈과 추가 항목 수로 처리한다. 남은 내용은 편집 모드의 상세 보기로 확인한다. 사용자 크기 조절로 숨겨진 항목도 표시 항목 설정에서는 유지한다.

설명 전문·부품 ID·스냅샷 식별자·원문 경로는 게임 위 요약에서 제외한다. 기존 무기 상세의 수치·조건·원문 열기와 접힌 진단 화면을 사용한다.

## 4 고정과 카드 관리

무기 상세에 무기 카드 고정 버튼을 추가한다. 계열 묶음 전체에 대한 고정 대신 실제 크기와 정의를 선택한 부품을 고정한다. 같은 ID에 여러 정의가 있으면 사용할 정의를 선택한 뒤 고정한다.

동일 종류·자료·부품 ID·정의의 카드가 이미 있으면 카드를 추가하지 않고 기존 카드를 선택한다. 기존 카드의 위치·크기·표시 항목은 그대로 유지한다. 크기 또는 자료가 다른 카드는 개별로 고정할 수 있다. 기존 전체 카드 한도 24개를 기술·무기·참조·변경 카드가 함께 사용한다.

고정 카드 목록에는 읽을 수 있는 이름·크기·카드 종류를 표시한다. 이름을 아직 읽지 못한 동안은 ID로 식별한다. 순서 변경·제거·중복 정리·표시 항목·상세 보기·개별 자료 갱신에 무기 카드를 연결한다. 카드 제거는 고정 정보만 삭제하고 저장한 게임 자료는 유지한다. 저장 실패 시 화면과 설정을 작업 전 상태로 돌린다.

## 5 기술과 상위 무기 연결

기술 상세의 관련 무기에서 계열과 크기를 선택하면 같은 자료의 무기 상세가 열린다. 여기서 무기 카드 고정을 누를 수 있다. 무기 상세의 요구 기술을 열면 기존 기술 카드 고정 버튼을 사용한다. 명시된 상위 부품을 열면 그 부품을 별도 무기 카드로 고정한다.

여러 요구 기술은 각각 선택한다. 기술과 무기를 한 번에 묶어 자동 고정하지 않고 사용자가 선택한 카드만 추가한다. 카드 사이의 연결은 탐색 관계이며, 어느 카드를 제거해도 다른 카드는 유지한다.

상위 부품은 upgrades_to에 명시되고 대상 정의를 찾은 경우에 연결한다. 크기나 이름을 보고 다음 단계를 만들어내지 않는다. 대상이 중복이면 후보를 고르게 하고, 누락이면 이동 상태만 알린다. 모든 이동은 출발 카드의 자료를 사용한다. 다른 크기나 새 자료로 가려면 사용자가 해당 대상을 선택한다.

편집 모드에서 카드의 상세 보기를 누르면 관리창의 기존 통합 상세가 열린다. 작은 카드 창 위에 추가 상세 창을 계속 쌓지 않는다. 뒤로 가기는 기존 검색어·필터·펼친 계열·선택·스크롤을 복원한다. 첫 추가 경로는 관리창의 무기 검색이며 기존 게임 위 기술 검색창의 검색 종류는 유지한다.

## 6 게임 위 조작과 복원

카드 보기에서는 클릭·드래그·키 입력을 게임으로 통과시킨다. 편집 모드에서 제목을 끌어 이동하고 크기를 조절한다. 상세 보기·카드 관리 동작도 편집 모드에서 사용한다. 수치를 누르는 동작으로 게임 입력을 가로채지 않는다.

기존 단축키·게임 창 식별·게임 최소화/창 전환 시 숨김·복귀·프로그램 종료 정리를 공통으로 사용한다. 게임이나 프로그램을 다시 켰을 때 기술 카드와 무기 카드의 순서·위치·크기·표시 항목·기존 공통 투명도 설정을 복원한다. 새 무기 카드는 보이는 게임 영역에 배치하며 화면 밖 좌표는 기존 위치 복구 규칙으로 보정한다.

## 7 자료 변경과 카드 갱신

카드는 고정 당시 저장 자료인 스냅샷을 계속 사용한다. 새 색인은 검색의 조회 자료를 바꾸되 고정 카드를 자동 갱신하지 않는다. 이전 자료 카드의 상세에서 새 자료로 보기를 사용해도 카드 자체는 변경하지 않는다.

최신 정의 선택·갱신은 같은 부품 ID의 후보를 새 자료에서 찾는다. 사용할 정의를 선택하고 이름·크기·선택 표시 수치·제작 비용·요구 기술·상위 부품의 전후 내용을 본 뒤 적용한다. 이 전후 표시는 같은 카드의 자료 갱신 확인에 사용한다.

갱신 뒤에도 카드 UID·순서·위치·크기·표시 항목을 유지한다. 새 정의가 이미 고정돼 있으면 기존 새 카드 선택 또는 취소를 제공하고, 카드를 자동 합치거나 삭제하지 않는다. 정의 누락·읽기 실패·취소 시 기존 카드를 보존한다. 갱신 대상이 더 이상 지원 무기 정의가 아니면 임의로 다른 카드 종류로 바꾸지 않는다.

기존 고정 카드 화면의 현재 데이터와 비교는 무기 카드에 맞는 이 전후 확인으로 연결한다. 기술/이벤트용 패치 비교 요청에 무기 ID를 그대로 보내지 않는다.

## 8 데이터와 기존 코드 연결

기존 WeaponService의 상세 응답에서 카드에 필요한 표시 데이터를 만든다. TXT/CSV 우선순위·숫자 단위·조건 상태·출처를 재해석하는 별도 카드 파서를 만들지 않는다. 같은 부품의 관리창과 카드가 같은 표시값을 사용하도록 연결한다. 게임 파일이나 전체 CSV를 카드 갱신마다 다시 읽지 않고 기존 스냅샷 서비스와 검증된 제품 캐시를 활용한다.

카드 설정은 종류 weapon과 도메인 component_template을 구분하고 스냅샷·부품 ID·선택 정의·표시 항목·위치를 저장한다. 게임 수치나 원문을 desktop.json에 복사하지 않는다. 기존 설정의 기술·참조·변경 카드와 누락된 기본 설정은 현재 로딩 방식으로 보존하고 새 무기 카드에만 무기용 초기 항목을 적용한다. 종류별 허용 도메인을 확인해 무기 카드가 참조/변경 카드 분기로 넘어가지 않게 한다.

기존 요약 그리기·일반 텍스트 렌더링·위치 제한·저장·작업 스레드를 재사용한다. 무기 요약 그리기와 항목 정의는 기술 전용 항목에서 분리하고 공통 카드 조작은 함께 사용한다. 예상 수정 지점은 desktop/settings.py, worker.py, app.py, weapon_browser.py와 무기 카드 표시 모듈이다. 수치 조회의 기존 응답으로 부족한 부분만 weapons.py에 표시용 응답을 추가한다.

카드 응답에는 UID·종류·자료·부품 ID·정의·언어·설정 세대를 묶는다. 삭제·갱신·언어/저장소 변경 후 도착한 과거 응답은 반영하지 않는다. 한 카드의 표시 데이터는 한 번에 적용하고 서로 다른 자료의 숫자를 섞지 않는다. 읽기 실패는 값을 0으로 바꾸거나 과거 정상값을 현재값으로 남기지 않고 카드에 짧은 오류 상태와 다시 읽기 경로를 제공한다. 카드의 저장 참조와 배치는 유지한다.

새 UI 프레임워크·외부 서비스·게임 메모리 접근은 추가하지 않는다.

## 9 이번 범위와 다음 단계

이번 범위는 개별 무기 카드의 고정·요약·편집·저장·복원·명시적 갱신과 기술/상위 부품 이동이다. 기존 기술 카드와 혼합해 사용할 수 있는 흐름까지 연결한다.

두 무기를 나란히 놓는 비교 화면·차이 강조·추천, 비교 결과 고정, 게임 위 무기 검색창 확장, 실전 DPS/승률·제국 보정·세이브 연구 상태·설계 자동 변경은 후속으로 둔다. 카드 두 장을 수동으로 고정하는 기능은 이번 범위에 포함한다.

## 10 개발 순서와 필수 완료 확인

개발 순서는 무기 카드 설정/표시 데이터 → 요약과 표시 항목 → 고정/중복/관리/저장 → 기술·상위 부품 이동 → 자료 갱신과 응답 일관성이다. 기능 작성 100% 이후 아래 필수 항목만 확인한다.

- 실제 청색 레이저의 개별 크기 고정, 기본 수치/자원 표시, 필요한 기술 및 상위 부품을 같은 자료에서 열고 추가 고정.
- 같은 무기 반복 고정 시 1장 유지, 다른 크기/다른 자료/중복 정의의 구분과 전체 카드 한도.
- 작은 카드·긴 한글 이름·여러 자원/요구 기술의 표시 및 상세 접근, 값 근거 패널이 다시 나타나지 않는 구성.
- 새 색인과 과거 카드 보존, 명시적 갱신의 전후 표시/취소/중복 대상, 늦은 응답·오류·저장 실패 처리.
- 기술/참조/변경 카드 설정 호환, 무기 카드와 혼합 저장·재시작·창 전환 복원, 보기 입력 통과와 편집 조작.

완료 기준은 청색 레이저 기술에서 소형 청색 레이저를 골라 고정하고, 무기 카드에서 상세를 열어 요구 기술과 상위 무기를 각각 추가 고정한 뒤, 게임으로 돌아가 필요한 카드만 남겨 사용하는 상태다. 커밋·푸시·PR·병합·배포는 별도 실행 범위로 둔다.
